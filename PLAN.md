---

## Design Direction

Create a **distinctive AI engineering / technical lab aesthetic**.

Think:

**AI Engineer's workspace + engineering documentation + premium editorial website**

NOT a typical developer portfolio.

Avoid common AI-generated designs:

* Generic purple/blue gradients
* Excessive glassmorphism
* Glowing cards
* Floating blobs
* Particle backgrounds
* Generic 3D AI illustrations
* Repetitive cards
* Same hover animation everywhere
* Excessive rounded boxes
* Gradient text everywhere
* Fake statistics
* Generic dashboard UI

Use strong typography, asymmetric layouts, technical labels, subtle grid/line elements, editorial spacing and controlled motion.

The website should feel **designed and intentional, not AI-generated**.
