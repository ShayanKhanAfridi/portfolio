# Shayan Khan Afridi — Portfolio

A premium, interactive personal portfolio built for AI, Software Engineering, and Full-Stack development. 

🌐 **Live Demo:** [https://shayankhanafridi.vercel.app/](https://shayankhanafridi.vercel.app/)

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion & GSAP
- **Canvas:** Native HTML5 Canvas API (Particle System)

## 📦 Features

- **Interactive Hero:** Custom terminal-style typing animations and a dynamic physics-based particle network background.
- **Project Showcase:** Detailed breakdowns of AI and full-stack projects featuring interactive video modals and tech-stack pipelines.
- **Experience & Education:** Chronological timelines with detailed technical achievements.
- **Custom Cursor:** Smooth, physics-based custom cursor with hover state awareness.
- **Responsive Design:** Completely optimized for mobile, tablet, and desktop devices with seamless layout shifts.

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
